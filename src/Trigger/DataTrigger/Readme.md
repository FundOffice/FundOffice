# 基金业务监控与规则校验模块

## 项目简介

本模块是基于 C\# 开发的基金业务自动化监控、规则校验组件，包含统一校验基类、风控规则、业务监控、流程触发四大核心能力，用于保障基金业务数据准确性、流程合规性，实现异常自动预警与业务闭环管理。

---



## 1\. 基础公共类

|文件名|核心功能|
|---|---|
|DataObserver|订阅数据的基类|
|VerifyRule|继承DataObserver<br>所有校验规则的抽象基类<br>・统一校验执行流程<br>・封装告警发送、告警撤销、参数管理等公共方法<br>・所有 `\*Rule` 规则的父类，保证代码标准化|

## 2\. 基金业务校验规则

所有规则用于基金业务数据 / 状态校验，异常自动触发告警，数据修复后自动撤销预警。

|文件名|功能描述|
|---|---|
|FundClearDateMissingRule|校验已进入清盘流程的基金是否缺失清盘日期，缺失则告警|
|FundClearNotFinishedRule|监控基金清盘流程执行状态，识别清盘超时、未完成等异常|
|FundDailyMissingRule|校验基金存续期内交易日净值数据完整性，自动识别缺失净值日期|
|FundNearLiquidationAlertRule|监控基金临近到期 / 清盘时间，达到阈值自动提前预警|
|FundOverdueRule|校验已过到期日但未完成清盘的基金，统计超期天数并预警|
|FundScaleRule|监控基金净资产规模，连续低于合规阈值时触发预警|
|FundSharePairRule|核心份额对账规则，比对净值统计份额与交易确认份额的一致性|
|FundStopPurchaseRule|根据基金规模 / 状态判断暂停申购条件，预测申购限制与清盘时间|

## 3\. 业务实时监控服务

持续监控业务状态，自动发现订单、交收、请求异常，生成待办 / 追踪任务。

|文件名|功能描述|
|---|---|
|FundSettlementMonitor|监控基金交易资金 / 份额交收状态，追踪未按时完成的交收业务|
|OrderValueIsWellMonitor|校验认购 / 申购 / 赎回订单的金额、规则合法性，拦截异常订单|
|RequestMissingMonitor|监控业务订单与划转请求匹配性，识别漏录单、无对应请求的异常订单|
|PeriodicalUnreportedMonitor|定期报告未上报提醒|

## 4\. 业务流程触发调度

根据业务条件自动触发流程、生成待办，实现业务自动化处理。

|文件名|功能描述|
|---|---|
|TransferRequestTriggers|自动触发基金资金 / 份额划转；识别巨额赎回并生成公告待办；联动清算结算流程|
